# Doorbell Ring Clip Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Record the first 15 s of video of every doorbell ring on the companion, archive the clips in Home Assistant, and show the latest ones in the intercom card as a playable carousel.

**Architecture:** The companion's ring holder feeds the shared stream's video packets to a new `RingClipRecorder`, which remuxes H.264 RTP into a progressive MP4 in pure Go and keeps one file per entrypoint, served at `/api/v3/entrypoints/{id}/clip/ring.mp4`. The integration downloads each new clip into Home Assistant's `local` media folder, purges old ones, and exposes a signed-URL list to the card through a WebSocket command. The card gets a stable skeleton so its player and carousel survive the per-`hass` re-render.

**Tech Stack:** Go 1.26, `gortsplib/v5/pkg/format/rtph264`, `mediacommon/v2` (`pmp4`, `codecs/h264`), pion/rtp; Home Assistant custom integration (Python 3.13, unittest); vanilla Web Component (no build step).

**Spec:** [docs/superpowers/specs/2026-10-26-ring-clip-design.md](../specs/2026-10-26-ring-clip-design.md)

## Global Constraints

- Clip length: the first **15 s** of video (`15 * 90000` RTP ticks), starting at the first IDR after an SPS and a PPS.
- Recording **stops at the answer**; the partial clip is kept.
- Clips under **1 s** are discarded; the previous file stays.
- Size cap: **8 MB** (`8 << 20`) of samples in memory.
- Companion file: `<CompanionDataDir>/clips/ring/<entrypoint id>.mp4`, one per entrypoint; temporary files `.ringclip-*.mp4`.
- The clip file's modification time is the **recorded time** (wall clock at the first IDR).
- State field: `ring_clip_recorded_at` (RFC 3339, millisecond precision, omitted when there is no clip).
- Home Assistant archive: `<media_dirs["local"]>/bticino_go/<slug(device_id)>/<slug(entrypoint_id)>/YYYY-MM-DD_HH-MM-SS.mp4`, poster `<same name>.jpg`.
- Retention option `clip_retention_days`: integer 0–3650, default **30**, `0` = never delete.
- Poster window: `ring_snapshot_updated_at` within **60 s** of `ring_clip_recorded_at`.
- Signed URL lifetime: **1 h**; the card reloads the list when it is older than **50 min**.
- Event: `bticino_companion_ring_clip_saved`. Camera attribute: `bticino_last_ring_clip_at`.
- WebSocket command: `bticino_companion/card_ring_clips`, `limit` 1–50, default 10.
- Card option `clips`: integer 0–50, default 10; `0` hides the carousel.
- Card copy stays in English like the rest of the card; dates and times are localized with `Intl`.

// writeSnapshot publishes image at path atomically: a reader sees the old file
// or the new one, never a partial JPEG.
func writeSnapshot(path string, image []byte) error {
	return writeFileAtomic(path, ".snapshot-*.jpg", image)
}

// writeFileAtomic writes data to a temporary file named after pattern next to
// path and renames it over path.
func writeFileAtomic(path, pattern string, data []byte) error {
	if err := os.MkdirAll(filepath.Dir(path), 0o750); err != nil {
		return fmt.Errorf("create directory: %w", err)
	}

	temporary, err := os.CreateTemp(filepath.Dir(path), pattern)
	if err != nil {
		return fmt.Errorf("create temporary file: %w", err)
	}

	temporaryPath := temporary.Name()
	defer os.Remove(temporaryPath) //nolint:errcheck // removed after successful rename too

	if _, err := temporary.Write(data); err != nil {
		_ = temporary.Close()
		return fmt.Errorf("write %s: %w", filepath.Base(path), err)
	}

	if err := temporary.Close(); err != nil {
		return fmt.Errorf("close %s: %w", filepath.Base(path), err)
	}

	if err := os.Rename(temporaryPath, path); err != nil {
		return fmt.Errorf("rename %s: %w", filepath.Base(path), err)
	}

	return nil
}

func (s *SnapshotManager) path(entrypointID string) (string, bool) {
	name, ok := entrypointFileName(entrypointID)
	if !ok {
		return "", false
	}

	return filepath.Join(s.dir, "snapshots", name+".jpg"), true
}

// entrypointFileName is the entrypoint id as a file name, refused when it could
// leave its directory.
func entrypointFileName(entrypointID string) (string, bool) {
	entrypointID = strings.TrimSpace(entrypointID)
	if entrypointID == "" || entrypointID == "." || entrypointID == ".." || filepath.Base(entrypointID) != entrypointID || strings.ContainsRune(entrypointID, filepath.Separator) {
		return "", false
	}

	return entrypointID, true
}

func TestClipWriterDepacketizesAggregatedAndFragmentedPackets(t *testing.T) {
	writer := newTestClipWriter(t)

	stapA := []byte{0x78}
	for _, nalu := range [][]byte{testClipSPS, testClipPPS} {

	fuStart := append([]byte{0x7c, 0x85}, testClipIDR[1:3]...)
	fuEnd := append([]byte{0x7c, 0x45}, testClipIDR[3:]...)

	}
}

import (

var ErrRingClipNotFound = errors.New("media: ring clip is not available yet")

const (
	ringClipMaxDuration      = 15 * time.Second
	ringClipMinDuration      = time.Second
	ringClipMaxBytes         = 8 << 20
	ringClipPacketBufferSize = 256
	ringClipTimescale        = 90000
	ringClipMaxTicks         = int64(ringClipMaxDuration/time.Second) * ringClipTimescale
	// ringClipDefaultSampleDuration is 1/30 s, the length given to the only
	// sample of a one-sample clip.
	ringClipDefaultSampleDuration = 3000
	ringClipTemporaryPattern      = ".ringclip-*.mp4"

// RingClipRecorder records the first seconds of video of every doorbell ring
// and keeps the last clip of each entrypoint. The ring holder feeds it, so a
// ring is recorded whether or not a card is open. See
// docs/superpowers/specs/2026-10-26-ring-clip-design.md.
type RingClipRecorder struct {
	mu      sync.Mutex
	dir     string
	logger  *slog.Logger
	active  *RingClip

// Start begins the clip of a new ring and closes the one still open: the
// intercom carries one stream at a time.
func (r *RingClipRecorder) Start(entrypointID string) *RingClip {
	if r == nil {
		return nil
	}

	path, ok := r.path(entrypointID)
	if !ok {
		return nil
	}

	writer, err := newClipWriter()
	if err != nil {
		r.logger.Warn("start ring clip", "entrypoint_id", entrypointID, "error", err)
		return nil

		recorder: r, entrypointID: entrypointID, path: path,
		packets: make(chan *rtp.Packet, ringClipPacketBufferSize),
		closed:  make(chan struct{}), done: make(chan struct{}),

	r.mu.Unlock()

// Open returns the last clip of an entrypoint and the time it was recorded.
func (r *RingClipRecorder) Open(entrypointID string) (*os.File, time.Time, error) {
	if r == nil {
		return nil, time.Time{}, ErrRingClipNotFound
	}

	path, ok := r.path(entrypointID)
	if !ok {
		return nil, time.Time{}, ErrRingClipNotFound
	}

	file, err := os.Open(path) // #nosec G304 -- built from a validated entrypoint id below the data directory.
	if errors.Is(err, os.ErrNotExist) {
		return nil, time.Time{}, ErrRingClipNotFound
	}

	if err != nil {
		return nil, time.Time{}, fmt.Errorf("open ring clip: %w", err)

	if err != nil {
		_ = file.Close()
		return nil, time.Time{}, fmt.Errorf("stat ring clip: %w", err)

	return file, info.ModTime(), nil
}

// VideoRTP queues a copy of a video packet. It never blocks the fan-out: a
// packet that finds the queue full is dropped.
func (c *RingClip) VideoRTP(packet *rtp.Packet) {
	if c == nil || packet == nil {
		return
	}

	select {
	case <-c.closed:
		return
	default:
	}

	select {
	case c.packets <- packet.Clone():
	default:
	}
}

// Close ends the clip: what was recorded is written, or discarded when too
// short. It returns at once.
func (c *RingClip) Close() {
	if c != nil {
		c.closeOnce.Do(func() { close(c.closed) })
	}
}

func (c *RingClip) run(writer *clipWriter) {
	defer close(c.done)
	defer c.finish(writer)

	for {
		select {
		case packet := <-c.packets:
			if writer.push(packet) {
				return
			}
		case <-c.closed:
			// What was queued before the close still belongs to the clip.
			for {
				select {
				case packet := <-c.packets:
					if writer.push(packet) {
						return
					}
				default:
					return
				}
			}
		}
	}
}

func (c *RingClip) finish(writer *clipWriter) {
	c.Close()

	recorder := c.recorder

	recorder.mu.Lock()
	if recorder.active == c {
		recorder.active = nil
	}
	recorder.mu.Unlock()

	duration := writer.duration()
	if duration < ringClipMinDuration {
		recorder.logger.Debug("ring clip discarded; too short", "entrypoint_id", c.entrypointID, "duration", duration)
		return
	}

	data, err := writer.marshal()
	if err != nil {
		recorder.logger.Warn("encode ring clip", "entrypoint_id", c.entrypointID, "error", err)
		return
	}

	if err := writeFileAtomic(c.path, ringClipTemporaryPattern, data); err != nil {
		recorder.logger.Warn("publish ring clip", "entrypoint_id", c.entrypointID, "error", err)
		return
	}

	// The modification time is the start of the clip: RecordedAt reads it back.
	if err := os.Chtimes(c.path, writer.recordedAt, writer.recordedAt); err != nil {
		recorder.logger.Warn("date ring clip", "entrypoint_id", c.entrypointID, "error", err)
	}

	recorder.logger.Debug("ring clip saved", "entrypoint_id", c.entrypointID, "duration", duration, "bytes", len(data))

	recorder.mu.Lock()
	callback := recorder.onSaved
	recorder.mu.Unlock()

	if callback != nil {
		callback()
	}
}

// clipWriter turns the intercom's H.264 RTP into the samples of one clip. One
// goroutine uses it.
type clipWriter struct {
	decoder        *rtph264.Decoder
	sps, pps       []byte
	started        bool
	firstTimestamp uint32
	recordedAt     time.Time
	samples        []clipSample
	size           int
}

type clipSample struct {
	pts     int64
	payload []byte
	idr     bool
}

func newClipWriter() (*clipWriter, error) {
	decoder := &rtph264.Decoder{PacketizationMode: 1}
	if err := decoder.Init(); err != nil {
		return nil, fmt.Errorf("init H.264 depacketizer: %w", err)
	}

	return &clipWriter{decoder: decoder}, nil
}

// push adds a packet and reports whether the clip is complete.
func (w *clipWriter) push(packet *rtp.Packet) bool {
	accessUnit, err := w.decoder.Decode(packet)
	if err != nil {
		// More packets needed, a fragment without its start, or a broken access
		// unit: none ends the clip, the next access unit may be fine.
		return false
	}

	return w.accessUnit(packet.Timestamp, accessUnit)
}

// accessUnit adds one access unit and reports whether the clip is complete.
func (w *clipWriter) accessUnit(timestamp uint32, accessUnit [][]byte) bool {
	var sps, pps []byte

	idr := false
	nalus := make([][]byte, 0, len(accessUnit))

	for _, nalu := range accessUnit {
		if len(nalu) == 0 {
			continue
		}

		switch h264.NALUType(nalu[0] & 0x1f) {
		case h264.NALUTypeSPS:
			sps = nalu
		case h264.NALUTypePPS:
			pps = nalu
		case h264.NALUTypeAccessUnitDelimiter:
		case h264.NALUTypeIDR:
			idr = true
			nalus = append(nalus, nalu)
		default:
			nalus = append(nalus, nalu)
		}
	}

	if !w.started {
		// The SDP carries no sprop-parameter-sets: SPS and PPS come in band.
		if sps != nil {
			w.sps = bytes.Clone(sps)
		}

		if pps != nil {
			w.pps = bytes.Clone(pps)
		}

		if !idr || w.sps == nil || w.pps == nil {
			return false
		}

		w.started = true
		w.firstTimestamp = timestamp
		w.recordedAt = time.Now()
	} else if sps != nil && !bytes.Equal(sps, w.sps) {
		// The stream changed format: one track cannot carry both.
		return true
	}

	if len(nalus) == 0 {
		return false
	}

	// A signed difference keeps the order across a timestamp wrap.
	pts := int64(int32(timestamp - w.firstTimestamp)) // #nosec G115 -- intentional wrap-around.
	if pts >= ringClipMaxTicks {
		return true
	}

	if n := len(w.samples); n > 0 && pts <= w.samples[n-1].pts {
		return false
	}

	payload, err := h264.AVCC(nalus).Marshal()
	if err != nil {
		return false
	}

	if w.size+len(payload) > ringClipMaxBytes {
		return true
	}

	w.samples = append(w.samples, clipSample{pts: pts, payload: payload, idr: idr})
	w.size += len(payload)

	return false
}

// sampleDuration is the gap to the next sample; the last repeats the one before.
func (w *clipWriter) sampleDuration(i int) int64 {
	switch {
	case i+1 < len(w.samples):
		return w.samples[i+1].pts - w.samples[i].pts
	case i > 0:
		return w.samples[i].pts - w.samples[i-1].pts
	default:
		return ringClipDefaultSampleDuration
	}
}

func (w *clipWriter) duration() time.Duration {
	n := len(w.samples)
	if n == 0 {
		return 0
	}

	return ticksToDuration(w.samples[n-1].pts + w.sampleDuration(n-1))
}

func (w *clipWriter) marshal() ([]byte, error) {
	samples := make([]*pmp4.Sample, len(w.samples))
	for i, sample := range w.samples {
		samples[i] = &pmp4.Sample{
			Duration:        uint32(w.sampleDuration(i)), // #nosec G115 -- bounded by ringClipMaxTicks.
			IsNonSyncSample: !sample.idr,
			PayloadSize:     uint32(len(sample.payload)), // #nosec G115 -- bounded by ringClipMaxBytes.
			GetPayload:      func() ([]byte, error) { return sample.payload, nil },
		}
	}

	presentation := pmp4.Presentation{Tracks: []*pmp4.Track{{
		ID:        1,
		TimeScale: ringClipTimescale,
		Codec:     &codecs.H264{SPS: w.sps, PPS: w.pps},
		Samples:   samples,
	}}}

	var buffer bytes.Buffer
	if err := presentation.Marshal(&buffer); err != nil {
		return nil, fmt.Errorf("marshal ring clip: %w", err)
	}

	return buffer.Bytes(), nil
}

func ticksToDuration(ticks int64) time.Duration {
	return time.Duration(ticks) * time.Second / ringClipTimescale
}

```python
"""Archive of the doorbell ring clips in Home Assistant's media folder.

The Companion keeps one clip per entrypoint; this archive keeps the history.
See docs/superpowers/specs/2026-10-26-ring-clip-design.md in the Companion
repository.
"""

from __future__ import annotations

import asyncio
import contextlib
from dataclasses import dataclass
from datetime import datetime, timedelta, timezone
import logging
import os
from pathlib import Path
import tempfile
from urllib.parse import quote

from homeassistant.config_entries import ConfigEntry
from homeassistant.core import CALLBACK_TYPE, HomeAssistant, callback
from homeassistant.helpers.event import async_track_time_interval
from homeassistant.util import dt as dt_util, slugify

from .api import CompanionApiError
from .const import (
    CLIP_ARCHIVE_FOLDER,
    CLIP_POSTER_WINDOW_SECONDS,
    CLIP_PURGE_INTERVAL_SECONDS,
    CONF_CLIP_RETENTION_DAYS,
    DEFAULT_CLIP_RETENTION_DAYS,
    EVENT_RING_CLIP_SAVED,
)
from .models import Entrypoint

_LOGGER = logging.getLogger(__name__)

CLIP_SUFFIX = ".mp4"
POSTER_SUFFIX = ".jpg"
NAME_FORMAT = "%Y-%m-%d_%H-%M-%S"


@dataclass(frozen=True, slots=True)
class ArchivedClip:
    """One clip in the archive."""

    recorded_at: datetime
    path: Path
    poster: Path | None


class RingClipArchiver:
    """Download every new ring clip of one Companion and purge old ones."""

    def __init__(self, hass: HomeAssistant, entry: ConfigEntry, coordinator, client, device_id: str) -> None:
        self._hass = hass
        self._coordinator = coordinator
        self._client = client
        self._retention_days = int(entry.options.get(CONF_CLIP_RETENTION_DAYS, DEFAULT_CLIP_RETENTION_DAYS))
        media_root = hass.config.media_dirs.get("local")
        self._media_root = Path(media_root) if media_root else None
        self._root = self._media_root / CLIP_ARCHIVE_FOLDER / slugify(device_id) if self._media_root else None
        # The clip time each entrypoint was last found archived, so a state push
        # that changes nothing costs nothing.
        self._checked: dict[str, datetime] = {}
        self._in_flight: set[tuple[str, datetime]] = set()
        self._latest: dict[str, datetime] = {}
        self._unsubscribers: list[CALLBACK_TYPE] = []
        self._tasks: set[asyncio.Task] = set()

    @property
    def enabled(self) -> bool:
        """Whether a local media folder exists to archive into."""
        return self._root is not None

    async def async_start(self) -> None:
        """Purge, then follow the Companion state for new clips."""
        if self._root is None:
            _LOGGER.warning("No 'local' media folder is configured; doorbell ring clips are not archived")
            return
        self._latest = await self._hass.async_add_executor_job(_scan_latest, self._root)
        await self._async_purge()
        self._unsubscribers.append(self._coordinator.async_add_listener(self._async_state_changed))
        self._unsubscribers.append(
            async_track_time_interval(
                self._hass, self._async_purge_interval, timedelta(seconds=CLIP_PURGE_INTERVAL_SECONDS)
            )
        )
        self._async_state_changed()

    async def async_stop(self) -> None:
        """Stop following the state and cancel downloads in flight."""
        for unsubscribe in self._unsubscribers:
            unsubscribe()
        self._unsubscribers.clear()
        for task in tuple(self._tasks):
            task.cancel()

    def latest(self, entrypoint_id: str) -> datetime | None:
        """The time of the newest archived clip of an entrypoint."""
        return self._latest.get(slugify(entrypoint_id))

    async def async_list(self, entrypoint_id: str, limit: int) -> list[ArchivedClip]:
        """The newest clips of an entrypoint, newest first."""
        if self._root is None:
            return []
        return await self._hass.async_add_executor_job(_list_clips, self._folder(entrypoint_id), limit)

    def url_path(self, path: Path) -> str:
        """The path Home Assistant serves an archived file at, before signing."""
        return "/media/local/" + quote(path.relative_to(self._media_root).as_posix())

    def _folder(self, entrypoint_id: str) -> Path:
        return self._root / slugify(entrypoint_id)

    @callback
    def _async_state_changed(self) -> None:
        state = self._coordinator.data
        if self._root is None or not state:
            return
        for entrypoint in state.entrypoints:
            recorded = entrypoint.ring_clip_recorded_at
            key = (entrypoint.id, recorded)
            if recorded is None or self._checked.get(entrypoint.id) == recorded or key in self._in_flight:
                continue
            self._in_flight.add(key)
            task = self._hass.async_create_background_task(
                self._async_archive(entrypoint, recorded), name=f"bticino_companion archive ring clip {entrypoint.id}"
            )
            self._tasks.add(task)
            task.add_done_callback(self._tasks.discard)

    async def _async_archive(self, entrypoint: Entrypoint, recorded: datetime) -> None:
        try:
            clip_path = self._folder(entrypoint.id) / f"{dt_util.as_local(recorded).strftime(NAME_FORMAT)}{CLIP_SUFFIX}"
            if await self._hass.async_add_executor_job(clip_path.exists):
                self._checked[entrypoint.id] = recorded
                return
            try:
                clip = await self._client.async_entrypoint_clip_ring(entrypoint.id)
            except CompanionApiError as err:
                # Still missing, so the next state push tries again.
                _LOGGER.warning("Unable to download the ring clip of %s: %s", entrypoint.id, err)
                return
            if not clip:
                return
            poster = await self._async_poster(entrypoint, recorded)
            poster_path = clip_path.with_suffix(POSTER_SUFFIX) if poster else None
            try:
                await self._hass.async_add_executor_job(_write_atomic, clip_path, clip, recorded)
                if poster and poster_path:
                    await self._hass.async_add_executor_job(_write_atomic, poster_path, poster, recorded)
            except OSError as err:
                _LOGGER.warning("Unable to archive the ring clip of %s: %s", entrypoint.id, err)
                return
            self._checked[entrypoint.id] = recorded
            folder = slugify(entrypoint.id)
            if recorded > self._latest.get(folder, datetime.min.replace(tzinfo=timezone.utc)):
                self._latest[folder] = recorded
            self._hass.bus.async_fire(
                EVENT_RING_CLIP_SAVED,
                {
                    "entrypoint_id": entrypoint.id,
                    "recorded_at": recorded.isoformat(),
                    "path": str(clip_path),
                    "poster_path": str(poster_path) if poster_path else None,
                    "media_content_id": "media-source://media_source/local/"
                    + clip_path.relative_to(self._media_root).as_posix(),
                },
            )
            self._coordinator.async_update_listeners()
            await self._async_purge()
        finally:
            self._in_flight.discard((entrypoint.id, recorded))

    async def _async_poster(self, entrypoint: Entrypoint, recorded: datetime) -> bytes | None:
        # The ring picture comes from the same stream, a moment after the clip
        # starts; a picture further away belongs to another ring.
        snapshot_at = entrypoint.ring_snapshot_updated_at
        if snapshot_at is None or abs((snapshot_at - recorded).total_seconds()) > CLIP_POSTER_WINDOW_SECONDS:
            return None
        try:
            return await self._client.async_entrypoint_snapshot_ring(entrypoint.id)
        except CompanionApiError as err:
            _LOGGER.debug("No poster for the ring clip of %s: %s", entrypoint.id, err)
            return None

    async def _async_purge(self) -> None:
        if self._root is None or self._retention_days <= 0:
            return
        cutoff = dt_util.utcnow() - timedelta(days=self._retention_days)
        await self._hass.async_add_executor_job(_purge, self._root, cutoff.timestamp())

    async def _async_purge_interval(self, _now: datetime) -> None:
        await self._async_purge()


def _write_atomic(path: Path, data: bytes, recorded: datetime) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)
    descriptor, temporary = tempfile.mkstemp(prefix=".tmp-", suffix=path.suffix, dir=path.parent)
    try:
        with os.fdopen(descriptor, "wb") as file:
            file.write(data)
        os.replace(temporary, path)
    except BaseException:
        with contextlib.suppress(OSError):
            os.unlink(temporary)
        raise
    os.utime(path, (recorded.timestamp(), recorded.timestamp()))


def _clips_in(folder: Path) -> list[Path]:
    if not folder.is_dir():
        return []
    return [path for path in folder.iterdir() if path.suffix == CLIP_SUFFIX and not path.name.startswith(".")]


def _scan_latest(root: Path) -> dict[str, datetime]:
    latest: dict[str, datetime] = {}
    if not root.is_dir():
        return latest
    for folder in root.iterdir():
        clips = _clips_in(folder)
        if clips:
            newest = max(path.stat().st_mtime for path in clips)
            latest[folder.name] = datetime.fromtimestamp(newest, timezone.utc)
    return latest


def _list_clips(folder: Path, limit: int) -> list[ArchivedClip]:
    clips = sorted(_clips_in(folder), key=lambda path: path.name, reverse=True)[:limit]
    result = []
    for path in clips:
        poster = path.with_suffix(POSTER_SUFFIX)
        result.append(
            ArchivedClip(
                recorded_at=datetime.fromtimestamp(path.stat().st_mtime, timezone.utc),
                path=path,
                poster=poster if poster.exists() else None,
            )
        )
    return result


def _purge(root: Path, cutoff: float) -> None:
    if not root.is_dir():
        return
    for folder in root.iterdir():
        if not folder.is_dir():
            continue
        for path in folder.iterdir():
            if path.suffix in (CLIP_SUFFIX, POSTER_SUFFIX) and path.stat().st_mtime < cutoff:
                with contextlib.suppress(OSError):
                    path.unlink()
        with contextlib.suppress(OSError):
            if not any(folder.iterdir()):
                folder.rmdir()
```

  _syncClips() {
    if (!this._config.clips) {
      if (this._clips.length || this._playing) {
        this._clips = [];
        this._closePlayback();
      }
      this._renderClips();
      return;

    const key = this._cameraState()?.attributes?.bticino_last_ring_clip_at || "";
    if (key === this._clipsKey) return;
    this._clipsKey = key;
    this._loadClips();
  }

  // One request at a time; a reload asked meanwhile runs once the current one ends.
  _loadClips() {
    if (this._clipsPromise) {
      this._clipsReload = true;
      return this._clipsPromise;
    }
    this._clipsPromise = this._fetchClips().finally(() => { this._clipsPromise = undefined; });
    return this._clipsPromise;
  }

  async _fetchClips() {
    this._clipsLoading = true;
    this._renderClips();
    try {
      do {
        this._clipsReload = false;
        const response = await this._send("bticino_companion/card_ring_clips", { limit: this._config.clips });
        this._clips = Array.isArray(response?.clips) ? response.clips : [];
        this._clipsLoadedAt = Date.now();
      } while (this._clipsReload);
    } catch (err) {
      // Clip errors never mix with call errors: the carousel just hides.
      this._clips = [];
      console.debug("bticino-go-intercom-card: ring clips unavailable", err);
    } finally {
      this._clipsLoading = false;
      this._clipsLoaded = true;
    }
    if (this._playing && !this._clips.some((clip) => clip.recorded_at === this._playing)) this._closePlayback();
    this._renderClips();
  }

      : this._clips.map((clip) => {
        const { day, time } = this._clipLabel(clip.recorded_at);
        const playing = clip.recorded_at === this._playing;

  _clipLabel(iso) {

    const language = this._hass?.locale?.language || navigator.language;
    const startOfDay = (value) => new Date(value.getFullYear(), value.getMonth(), value.getDate());

  async _play(recordedAt) {
    // The doorbell comes first: no clip while it rings or a call is up.
    if (this._isRinging() || this._pc || this._connecting || this._callState() === "active") return;
    // Signed URLs last an hour: reload a list older than 50 minutes first.
    if (Date.now() - this._clipsLoadedAt > 50 * 60 * 1000) await this._loadClips();
    const clip = this._clips.find((item) => item.recorded_at === recordedAt);
    if (!clip) return;
    this._playing = recordedAt;
    this._renderPlayback(clip);
    this._renderClips();

  _renderPlayback(clip) {
    const layer = this.shadowRoot?.querySelector(".playback");
    if (!layer) return;
    if (!this._playing || !clip) {
      layer.classList.add("hidden");
      layer.innerHTML = "";
      return;
    }
    const { day, time } = this._clipLabel(clip.recorded_at);
    const poster = clip.poster_url ? ` poster="${this._escape(this._hass.hassUrl(clip.poster_url))}"` : "";
    // Muted for autoplay: the clip has no audio anyway.
    layer.innerHTML = `
      <video controls autoplay playsinline muted preload="auto"${poster} src="${this._escape(this._hass.hassUrl(clip.url))}"></video>
      <div class="playback-bar"><span>${this._escape(day)} · ${this._escape(time)}</span><button class="round playback-close" title="Close" aria-label="Close clip"><ha-icon icon="mdi:close"></ha-icon></button></div>
      <button class="round replay hidden" title="Replay" aria-label="Replay clip"><ha-icon icon="mdi:replay"></ha-icon></button>
      <div class="playback-error hidden"><ha-icon icon="mdi:video-off"></ha-icon><span>Clip unavailable</span></div>`;
    layer.classList.remove("hidden");
    const video = layer.querySelector("video");
    const replay = layer.querySelector(".replay");
    video.addEventListener("ended", () => replay.classList.remove("hidden"));
    video.addEventListener("play", () => replay.classList.add("hidden"));
    video.addEventListener("error", () => {
      // A file purged meanwhile, or an expired URL: say so and refresh the list.
      video.classList.add("hidden");
      layer.querySelector(".playback-error").classList.remove("hidden");
      this._loadClips();
    });
    replay.addEventListener("click", () => {
      video.currentTime = 0;
      video.play().catch(() => {});
    });
    layer.querySelector(".playback-close").addEventListener("click", () => this._closePlayback());
  }

  _closePlayback() {
    if (!this._playing) return;
    this._playing = undefined;
    this._renderPlayback();
    this._renderClips();
